# MSc_thesis - Semi-supervised VAE Representation Learning for Fiber-seq Data
Master’s thesis project developing variational autoencoder (VAE) architectures for representation learning on long-read epigenomic sequencing data (Fiber-seq), capturing DNA methylation and chromatin accessibility to gain insights into chromatin regulatory states.

Files:
-VariationalAutoencoder_SemiS.py: VAE architecture implementation
-TrainingVAE_SS.ipynb: Notebook for training the VAE
-Loading.py: Data loading
Some data preprocessing files are not included in this repository.

Research Context:
This work was conducted as part of my master’s thesis during an internship at the VIB–KU Leuven Center for Cancer Biology, in the Laboratory of Integrative Genomics.
